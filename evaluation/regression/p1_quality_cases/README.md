# P1 offline quality cases

This directory is the provider-free regression inventory for Quality Sprint 1.
The frozen application answers remain in
`evaluation/results/formal_20260914_p0_quality_sprint1_1_final/` and are never
regenerated by this suite.

The inventory is assembled by `python -m evaluation.p1_quality --all` from:

- every English semantic regression in the P0-vs-P1.1 diff;
- key retrieval and citation failures;
- `EN-007`, `ZH-034`, `ZH-044`, and the multi-turn follow-up cases;
- Tesla period-sensitive cases;
- deterministic table-retrieval cases for revenue, margins, EPS, net income,
  cash flow, segment metrics, and operating income.

The runner exercises query scope/routing, the production `HybridRetriever`
with a seeded in-memory fixture, and deterministic citation checks. It does
not import or call an LLM provider, does not require network access, and does
not mutate the running Docker services.
