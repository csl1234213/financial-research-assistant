# Financial RAG Assistant v7.3.3

**Release Date:** 2026-07-20

**Tag:** `v7.3.3` (ec8b0a6)

---

## Highlights

Production-ready AI financial research copilot with a full-stack deployment.

- **Agentic RAG Workflow** — Intent-driven multi-step research with structured planning
- **Hybrid Retrieval** — Semantic + keyword search with transparent similarity scoring
- **Citation-Aware Generation** — Every output traceable to source documents with confidence scores
- **Knowledge Management** — PDF upload, auto-indexing, chunk exploration, persistent vector store
- **Docker Deployment** — One-command `docker compose up -d` production launch

---

## Architecture

See [System Architecture](../SYSTEM_ARCHITECTURE.md) for detailed architecture and design decisions.

```
User → React Frontend → Nginx → FastAPI → Agent Runtime → Hybrid Retriever → ChromaDB → LLM
```

### Key Components

| Component | Technology | Description |
|-----------|-----------|-------------|
| Frontend | React 18 + Vite + TypeScript | Chat, Knowledge, Retrieval pages |
| Reverse Proxy | Nginx 1.27 | SPA fallback, API proxy, static asset caching |
| API Server | FastAPI 0.115 | RESTful API with Swagger docs |
| Agent Runtime | Python | Intent routing, query planning, multi-strategy execution |
| Retriever | Hybrid (Semantic + Keyword) | sentence-transformers embeddings + BM25 keyword |
| Vector Store | ChromaDB 0.6.3 | Persistent storage with health check |
| LLM Provider | DeepSeek / Gemini / Claude | Factory pattern with provider abstraction |

## Installation

### Prerequisites

- Docker >= 24
- Docker Compose >= 2

### One-Command Start

```bash
git clone https://github.com/csl1234213/financial-rag-assistant.git
cd financial-rag-assistant
git checkout v7.3.3
cp .env.example .env
docker compose up -d
```

### Access

| Service | URL |
|---------|-----|
| Frontend | http://localhost:3000 |
| API Docs | http://localhost:8000/docs |
| Health Check | http://localhost:8000/api/v1/health |

## What's Changed

### New Features

- React-based Financial Copilot UI with three pages: Chat, Knowledge, Retrieval
- Knowledge Workspace: PDF upload, document indexing, chunk explorer
- Retrieval Playground: hybrid search debugging with similarity scores
- Citation system with evidence tracking and source reference
- Docker production deployment: backend, frontend, ChromaDB containers
- Demo knowledge base auto-bootstrap

### Improvements

- CI/CD pipeline covering Python, React, and Docker builds
- Test coverage >= 85% with 1000+ tests
- Docker health checks with proper start_period for slow-start services
- nginx reverse proxy with SPA fallback and API proxy
